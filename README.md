# BS-Traders-Website-Project

## About The Project
This is a fully responsive, static corporate website developed for **BS Traders Distributor**, a pharmaceutical and medical supplies distribution company in Pakistan. The website is designed to professionally showcase their business divisions, hospital networks, and partner brands.

## Technologies Used
* **HTML5 & CSS3:** For structural semantic markup and custom styling.
* **Vanilla JavaScript:** For mobile navigation, scroll-reveal animations, and dynamic statistic counters.
* **Swiper.js:** For the interactive partner brands carousel.

## Key Features
* Fully responsive layout adapted for mobile, tablet, and desktop viewing.
* Performance optimized with scroll-triggered animations (using Intersection Observer).
* Modern UI/UX design tailored for the healthcare sector.
